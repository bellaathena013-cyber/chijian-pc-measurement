## 运行

在本项目根目录用 PowerShell 运行。当前电脑已创建 `.venv` 并安装依赖；无需再次安装。

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe scripts/run_simulation.py
.\.venv\Scripts\python.exe main.py outputs/simulation/marker_150mm/input.png --layout config/layout.example.json --marker-size-mm 150 --output outputs/demo
```

换电脑时使用 Python 3.12 创建隔离环境，然后安装依赖：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

真实照片示例（先用现场实测数据编写 `config/site-layout.json`）：

```powershell
.\.venv\Scripts\python.exe main.py "samples/real/PC-W01.jpg" --layout config/site-layout.json --component-id PC-W01 --design-length-mm 4000 --design-width-mm 1000 --marker-size-mm 150 --tolerance-mm 50 --output outputs/PC-W01
```

生成标准标志：

```powershell
.\.venv\Scripts\python.exe scripts/generate_markers.py --size-mm 150
```

生成ID 0、1、2、3，字典为 `DICT_4X4_50`。PNG包含25%白边及DPI元数据，打印机仍可能自动缩放，必须打印后量黑色方块的横竖边长。布局图案均应按生成图方向放置；旋转时更新 `rotation_deg`（平面坐标x向右、y向下，正值为顺时针）。不使用普通数字块代替ArUco。

## 人工辅助接口

自动边界失败返回 `MANUAL_REQUIRED`。工作台支持点选四角、拖动调整和键盘输入坐标。CLI 也可创建JSON文件，填写**归一化原图** `outputs/.../original.png` 中沿边界顺序的四组像素坐标，不能使用缩略图坐标或校正图坐标。

```json
[[620,362],[446,954],[2389,994],[2437,403]]
```

上述数值仅演示格式。模拟样例会生成准确的 `truth_corners.json` 供回归测试，这些真值坐标不是自动测量输入，也不能冒充人工操作效果。

```powershell
.\.venv\Scripts\python.exe main.py outputs/simulation/manual_recovery/input.png --layout config/layout.example.json --manual-corners outputs/simulation/manual_recovery/truth_corners.json --output outputs/manual-demo
```

修改JSON四角可调整边界；`--selected-marker-ids 0 1 2 3`选择布局对应标志，选其他ID需同时提供对应布局；替换输入文件可重新上传/检测。人工模式仍经过标志及几何门禁，不能绕过缺标志、错误布局和明显非矩形问题。

## 输出与状态

每次输出原图、标注图、可用时的校正图及校正标注图、`result.json`和参数文件。JSON中的图片为本地绝对路径，不是可直接传给元筑的URL。新平台图片存储与展示方式待实测。

| 状态 | 含义 |
| --- | --- |
| PASS | 本轮质量门禁通过，长宽偏差均在配置阈值内；仅比赛原型结果 |
| REVIEW | 已计算尺寸，但偏差超限或标志质量存在警告，需人工复核 |
| MANUAL_REQUIRED | 标定可用，但边界不存在、歧义或非矩形，需人工处理 |
| RETAKE | 标志缺失、标定不可靠、极端视角或超出测量区域，不输出尺寸 |
| INVALID_INPUT | 参数、布局、图片或人工角点无效 |

`success=true`表示获得有效尺寸，**不表示质检通过**。必须同时读`result`。CLI有测量时退出码0，无法测量时退出码2。上下游应清除之前的结果，不把旧图片或旧尺寸当作本次成功输出。

程序的设计值仅参与最后比较。`length_error_mm`和`width_error_mm`为相对设计值的带符号偏差；模拟测试表的误差则相对独立真值。50 mm是可配置比赛阈值，不是正式工程规范，也不是不确定度估计。

## 已知限制与下一阶段

目前仅覆盖规则平面矩形、清晰边缘、已知四标志布局。明显阴影形成额外矩形时转人工。没有完成现场手机镜头畸变、高差、混凝土纹理、外露钢筋、遮挡及标志翘曲验证。共面性与打印尺寸仍需人工核对，重投影残差小不能证明现场精度。

企业资料、真实照片、虚拟环境、临时提取文件、输出图及 `.env` 均已排除Git。源码不含登录密码、API密钥或平台令牌。

## 已发布的试验模型

仓库包含训练后的构件上表面分割权重 `models/component-v1/best.pt`（SHA-256：`8094b4ba8d4c432e1ec455a850dd5ce86f933d2452ad0d30baccbc76e774f628`）。网站和单图预测默认读取此文件；照片识别仍需按 `requirements-training.txt` 配置独立推理环境。模型基于 YOLO11n-seg 预训练权重微调，只在少量同场地照片上验证，输出尺寸仍须人工复核。基础模型及相关使用遵循 Ultralytics 许可条款。
