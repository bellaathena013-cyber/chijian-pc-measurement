# 失败照片诊断优化（2026-10-02）

本轮改善失败原因的展示，不调整模型权重、标志检测阈值或尺寸计算算法。

## 改动

之前只有构件边界可用时才继续找标志，因此边界失败会让网页看起来一个标志也没找到。现在照片测量会独立检测标志：即使边界失败，仍可查看候选框和标志放大图。

网页分别显示整图候选数量、目标构件内数量和实际标定数量。边界不可靠时“目标内”显示“未确定”，实际标定为 0，不用识别候选数代替测量成功。旧历史记录缺少新字段时显示“历史记录显示标志”，不猜测其检测或标定数量。

增加按情形给出的建议：拍全构件并改善拍摄角度、使至少三个分散标志清晰入镜，或核对标志是否位于同一构件。识别到三个候选仍不代表具备可靠标定条件。
