# 尺见 · PC 构件尺寸测量网站使用说明

适用版本：2026 年 10 月 2 日｜本地比赛原型

## 一、这个网站能做什么

上传一张带有已知尺寸标志卡的构件照片，系统识别构件上表面和标志，尝试计算构件的平面长边、短边，并显示边界、标志细节和复核提示。

你不需要提前输入构件的卷尺长宽。已知的是标志卡的实际尺寸，构件尺寸由照片计算。当前系统不生成三维模型，不测厚度，也不替代现场验收。

**本批普通数字卡片请选择“真实照片识别（试验）”，标志黑色外框边长填写 150 mm。**

## 二、打开网站

当前电脑已经配置好运行环境。如果网站服务正在运行，直接打开：

http://127.0.0.1:8765/

如果打不开，在项目文件夹打开 PowerShell，运行：

```powershell
.\start-workbench.ps1
```

项目文件夹：`C:\Users\jiang\Documents\ChatGPT\湖南建工平台项目`。

启动后保持该终端窗口打开，再访问上面的地址。使用完成后，可在启动服务的终端按 Ctrl+C 停止服务。

本地使用不需要登录 aTrust。照片在本机处理，结果保存在本机。这个地址只适用于运行服务的电脑；发给老师后，老师不能通过自己电脑上的同一地址访问你的服务。换电脑运行需要另行配置运行环境和模型，单独复制网页文件不够。

## 三、拍摄前准备

1. 选择上表面轮廓清楚、适合用四边形表示的构件，尽量让画面以一个待测构件为主。
2. 在待测表面放置同尺寸的普通数字标志卡。至少要有 3 个清晰、分散且可用的标志，建议拍全 4 个。放了 3 个不等于一定能测量。
3. 标志卡应平整，并与待测上表面齐平；不要一部分放在上表面、一部分放在侧面或下层构件上。
4. 实测标志卡黑色外框的整体边长。本批已确认是 150 mm；换一批打印件后应重新测量。
5. 拍全构件上表面、四角和标志，避免遮挡、反光、模糊和过低的拍摄角度。尽量让标志在照片里足够大、边角清楚。
6. 上传原始照片，尽量不用截图、拼图、带尺寸文字的处理图或聊天软件压缩后的图片。

**“标志黑边”指黑色外框最外侧的边长，不是边框线条的粗细，不是纸张宽度，也不是内部黑色方块的边长。** 本批应填 150，不填 5 或 100。

## 四、真实照片测量：按这 7 步操作

1. 在“测量方式”中选择 **真实照片识别（试验）**。
2. 点击“构件原始照片”，选择 JPG、PNG 或 WebP 图片。单张最大 20 MB；系统另有 3200 万像素限制。
3. 填写“构件编号”，例如 `PC-W01`，方便在历史记录中查找。
4. “标志黑边 / mm”填写 **150**，前提是使用本批已实测的卡片。
5. 确认实际拍摄满足条件，再勾选“已实测标志黑色外框边长，且标志与构件上表面齐平”。勾选不会自动纠正拍摄条件。
6. 点击 **识别并计算尺寸**，等待本机处理。服务启动时会提前准备模型。页面显示“模型已就绪”后再演示更稳妥；若刚启动就提交，仍可能等待。等待期间会显示已用时间，不要重复提交。
7. 查看尺寸、边界标注、标志细节和复核原因，需要保留时点击“下载本次结果 JSON”。

照片模式不需要填写构件设计长宽、卷尺长宽或标志之间的距离。如果你看到“现场标志布局”，请先检查是否选成了 ArUco 模式。

点击“运行模拟演示”后，页面会切换到 ArUco 模式。测量自己的数字卡片照片前，要重新选回“真实照片识别（试验）”。

## 五、怎么看结果

### 1. 尺寸和状态

长边、短边的单位都是毫米。比如显示 `2792.8 × 1412.6 mm`，约等于 `2.793 × 1.413 m`。小数位不代表实际精度达到 0.1 mm。

| 页面状态 | 代表什么 | 应该怎么做 |
| --- | --- | --- |
| 试验尺寸 | 已算出尺寸，未触发当前流程的部分复核条件 | 仍需结合边界、标志和卷尺核验 |
| 需要复核 | 可能已算出尺寸，但存在标定或边界稳定性等疑点 | 阅读提示，检查对应标志和轮廓；必要时重拍 |
| 需人工复核或重拍 | 自动边界或其他关键步骤没有可靠完成 | 调整拍摄条件后重试；照片模式暂不支持网页手动改四角 |
| 请重新拍摄 | 标志不足或照片条件不能支撑本次测量 | 根据提示补足清晰标志、拍全构件后重拍 |
| 请检查输入 | 图片或参数不符合要求 | 检查文件、标志边长及确认项 |

没有尺寸时，表示本次未得到可用的计算结果，不表示构件尺寸为零。照片模式不会给出“本轮通过”；模拟或布局模式中的“本轮通过”也不能当作真实现场精度证明。

### 2. 看三个图

- **原图**：核对是否上传了正确照片。
- **边界标注**：检查轮廓是否沿着待测构件的上表面，有没有把侧面、钢筋或下层构件算进去。
- **标志细节**：放大检查卡片及候选角点，结合提示判断卡片是否模糊、遮挡或选错位置。

`C1、C2、C3…` 是系统给候选卡片分配的编号，不代表卡片上印刷的数字。

照片模式的“透视校正”和“手动修正四角”当前不可用，按钮变灰是正常的。

### 3. 看标志数量

| 页面提示 | 含义 |
| --- | --- |
| 整图候选 | 整张照片中检测到的可能标志，可能包含误检或其他构件上的标志 |
| 目标内 | 位于识别出的目标构件轮廓内的候选数；“未确定”表示尚不能确认所属目标 |
| 实际标定 | 本次成功标定实际使用的标志数 |

例如“整图候选 3 个 · 目标内未确定 · 实际标定 0 个”表示找到了候选，但未完成有效标定，不能据此认为已测量成功。

### 4. 动态展示识别过程

真实照片处理完成后，页面会自动播放“识别过程回放”（系统启用减少动态效果时，默认停在第一步）。回放依次展示原始照片、模型选中的构件区域、拟合边界与标志候选、测量结果。

- 点击“暂停”停止自动播放，再点击“播放 / 重播”继续；到最后一步后可从头重播。切到其他标签页后暂停，返回时恢复；主动暂停则不会自动恢复。若回放图片加载失败，点击结果旁的“重新加载回放”，不用重新上传。
- 点击任一步骤可单独讲解；点击“直接看结果”跳到最后一步。
- 绿色区域是模型选中的区域，橙色线是拟合边界，蓝框是标志候选。颜色只是区分信息，不表示验收合格。
- 这是基于本次真实识别结果的动态回放，不是模型内部实时运算视频，也不是实时进度百分比。处理期间显示原始照片和等待提示。
- 未识别成功时，只展示实际得到的信息，并说明没有可靠边界或尺寸。旧记录未保存模型区域时会明确提示，不补画区域。
- 点击“原图”“边界标注”“标志细节”可切换静态图片，自动播放会停止。

## 六、保存和查看历史

1. 本次处理完成后，点击顶部“检测记录”进入独立页面，列表展示本机最近 30 次。首页不再展示历史列表。
2. 点击“查看详情”，可以重新查看该次图片、尺寸和提示，也可以播放识别过程。点击“返回记录列表”切回列表。
3. 点击“下载本次结果 JSON”，保存结构化结果。JSON 不是 Word 或 PDF 报告，也不包含图片文件本身。
4. 历史记录只供查看。要重新测量，请重新选择照片并提交；左侧输入框不会因为查看历史而自动变成该次测量的参数。

给老师展示时，建议同时展示边界标注、尺寸和状态提示，不要只截取一个尺寸数字。下载结果中可能含本机图片地址，发送 JSON 不等于发送整套可离线查看的图片报告。

## 七、ArUco 布局测量怎么用

这一模式适用于专用 ArUco 编码标志，与目前印有普通数字 1、2、3、4 的卡片不同。普通数字卡片不能替代 ArUco 标志。

如确实使用本项目对应的 ArUco 标志，选择“ArUco 布局测量”，上传照片并填写设计长边、设计短边、标志黑边和允许偏差。展开“现场标志布局”，填写实测布局。

简化矩形布局要求：四个标志中心组成矩形，左上 ID 0、右上 ID 1、右下 ID 2、左下 ID 3，四张纸顶部朝同一方向。需要核对四边和两条对角线。

| 输入项 | 填写内容 | 例子 |
| --- | --- | --- |
| 横向中心间距 / mm | 左侧与右侧标志中心的实测距离 | 3 米填写 3000 |
| 纵向中心间距 / mm | 上方与下方标志中心的实测距离 | 1 米填写 1000 |

**不能把构件的长宽当作标志中心间距。输入 3 和 1，表示 3 毫米和 1 毫米。** 不符合简化布局的情况需要正确的完整布局 JSON，不能随意填写；上传 JSON 时会优先使用文件。

确认标志尺寸、相对位置和共面条件后开始测量。如果系统具备有效标定且允许手动编辑，可以点击“手动修正四角”，沿构件轮廓顺序选四个角，例如左上、右上、右下、左下。不要交叉选点；可以拖动调整、撤销一点或重新选择，最后点击“用这四点重新测量”。

## 八、常见问题

| 问题 | 处理办法 |
| --- | --- |
| 不知道该选哪种模式 | 本批普通数字卡片用“真实照片识别（试验）”；专用编码标志才用 ArUco |
| 提示标志不够 | 拍全至少 3 个清晰、分散的同尺寸标志，建议 4 个；提高卡片在照片中的清晰度 |
| 识别到了标志，却没有尺寸 | 查看构件边界及实际标定数；找到卡片只是测量的一个环节 |
| 边界落到侧面或其他构件 | 提高拍摄角度，拍全上表面，减少遮挡和其他构件的干扰 |
| 出了尺寸，但提示需要复核 | 按提示检查轮廓和卡片，与卷尺实测比较；不要通过修改标志尺寸来凑结果 |
| 第一次处理较慢 | 首次需要加载模型，等待处理完成；若页面明确报超时，再检查服务状态 |
| 提示模型不可用 | 需要恢复本机模型权重和推理环境，重新启动服务；不是登录 aTrust 就能解决 |
| 网页打不开 | 确认启动脚本仍在运行，地址为本机的 http://127.0.0.1:8765/ |
| 图片上传失败 | 检查格式、大小、像素数和文件是否损坏；处理图片时不要裁掉构件或标志 |

## 九、给老师演示的简短流程

先说明：“这是通过已知尺寸标志，计算构件平面长宽的本地试验系统。”

随后选择真实照片模式，上传原图，填写标志黑色外框 150 mm，核对共面条件并运行。播放“识别过程回放”，按原图、构件识别、边界与标志、测量结果的顺序讲解，再展示标志细节和复核原因。最后进入顶部“检测记录”或下载结果。

如展示“运行模拟演示”，明确说明这是模拟样例。系统仍在原型验证阶段，目前能处理部分照片，但并非所有现场照片都能可靠测量；输出尺寸后仍应实测复核。
