# 视觉测量 PoC 方案与拍摄规范

## 实施边界

首轮实现 ArUco 标定平面上的矩形长宽测量。场景为整块规则构件的一个平面，需清晰外轮廓；不把外露钢筋计入混凝土主体尺寸。以 CLI 和模块接口验证算法，随后才开发工作台和 FastAPI。

## 几何基准是首要条件

四个标志随意摆放，仅给每个标志边长，不能直接把四个中心映射到一个任意长宽的矩形。这样会把人为设定的比例误当测量结果。单个已知正方形在理想共面条件下可以确定局部度量单应性，但用100 mm小标志外推4 m时角点误差会被放大。

因此第一版选择**相对位置已知的四标志布局**：记录每个ID的中心毫米坐标和旋转方向，使用全部16个角点共同拟合平面单应性。这是当前PoC额外的拍摄前提；不是声称四个散放标志已实现可靠测量。现场可用固定布置基准、测量架或经卷尺核对的矩形标志布局降低每次布置成本。不能拿构件设计尺寸冒充标志间距。

示例配置的四标志中心为 `(0,0)`、`(4400,0)`、`(4400,1400)`、`(0,1400)` mm。数值只是模拟布局，现场必须测量后改配置，不是构件尺寸。标志大小独立可配置，角点由标准图案的方向确定。

依据：[OpenCV ArUco Boards](https://docs.opencv.org/4.13.0/db/da9/tutorial_aruco_board_detection.html)区分已知相对位置的板和独立标志；[单应性说明](https://docs.opencv.org/4.13.0/d9/dab/tutorial_homography.html)说明平面点映射；[ArUco 检测](https://docs.opencv.org/4.13.0/d5/dae/tutorial_aruco_detection.html)提供标准角点与ID检测。上述资料用于几何和API依据，不证明本项目现场精度。

## 处理步骤

1. Pillow读取并应用EXIF方向；保留归一化原图，检查格式、分辨率与内存上限。
2. OpenCV `DICT_4X4_50` 标准字典，亚像素角点细化；记录ID、四角、标志像素边长、局部清晰度和透视压缩情况。
3. 要求四个配置标志齐全且ID唯一；匹配已知毫米坐标，RANSAC拟合；检查各标志残差、留一标志交叉预测误差、图像覆盖和局部尺度变化。配置与照片不符则重拍/核对布局，不强行校正。
4. 在标志包围区域生成固定毫米比例校正图。候选边界使用灰度、阈值、Canny、轮廓和四边形拟合；剔除标志、触边对象和歧义候选，不使用设计长宽挑选“最符合答案”的轮廓。
5. 自动边界不唯一或不符合矩形假设时返回 `MANUAL_REQUIRED`。CLI可传入EXIF归一化原图上的四角坐标；后续页面提供点击、拖动、重选和重新上传。
6. 用单应性将原图角点转换为毫米坐标，以对边长度平均值求长宽，并核查直角和对边一致性。长边定义为length，短边定义为width，输入设计值须采用同一约定。
7. 使用未舍入值计算偏差及阈值判断；显示值再舍入。可靠性检查失败时不返回PASS。保存输入配置、检测证据、变换矩阵、JSON和图片。

单应性不会自动消除镜头畸变，也不能解决不共面、高差或错量表面。标志重投影残差小也不是整幅照片绝对误差小的证明。当前阈值为保守启发式，需真实样本校准；先约束拍摄，不提前开发相机标定系统。

## 真实构件拍摄规范

- 首批建议2—3块规则矩形构件，每块6—10张照片：正视或接近俯视、左右温和倾斜、远近变化、轻微阴影、横竖屏；另拍少量缺标志、遮挡、模糊等反例，不只挑最好看的照片。
- 使用本项目生成的4个不同ID ArUco。`marker_size_mm`指**黑色外边框的实际边长**，不包括白色留边或纸张。先可试100 mm；若全景中太小，则改150—200 mm并更新参数，以实测效果选择。打印禁止“适应页面”悄悄缩放；横竖各量一次，保持正方形、平整和哑光。
- 四个标志应包围被测轮廓，保持指定ID、朝向及经测量的相对位置。白边完整，无遮挡。现场测量中心间距与对角线并记录布局，摆放改变后更新配置。
- **标志必须与被测构件表面同平面。** 不要把标志放地面、构件表面在上方几十厘米；若放在延伸支撑上，支撑顶面必须齐平。单张照片不能可靠自动判断共面性，拍摄者负责确认。
- 构件本体完整入镜，四周留余量，避免边缘被画面裁切、钢筋或邻近构件遮挡。标志和边界都要清晰；尽量让每个标志短边达到60像素以上，这是拍摄起点建议，需现场验证。
- 使用手机普通主摄，避免0.5倍超广角、美颜、景深虚化、全景拼接和聊天软件压缩；镜头擦净、对焦、稳定拍摄，光线均匀。优先原始JPG/PNG，保留EXIF；HEIC先以原尺寸转换。
- 采用安全站位、适度抬高拍摄，避免贴地极斜角度；不为拍照攀爬不安全设施。可先使远近两端标志看起来大小接近，再逐步增加倾角做实验。
- 提供卷尺实测长宽，不只提供设计尺寸。建议两条长边、两条短边各测一次并记录表面、端点和单位；注明是混凝土本体还是包含其他突出物。本版只测本体。
- 随照片记录：图片编号、构件编号、设计长宽、实测两组长宽、手机型号/焦段、标志实测边长、布局文件、阴影/遮挡情况。至少保留一组未参与算法调整的照片作为最终检验集。

自动失败时，重新上传、重选正确布局或人工选四角都可以恢复流程；人工角点只能修复边界识别，不能补救标志缺失、错误尺寸或不共面标定。

## 模拟验证与现场验证

模拟从独立真值4000×1000 mm矩形出发，绘制真实标准ArUco图案，再施加旋转、透视、分辨率变化、阴影与模糊。程序必须从图像重新检测标志和构件，不把真值角点直接当检测输入。人工模式另行测试。增加非4000×1000的尺寸，确保算法没有把设计值当答案。

记录真值、测量值、长宽绝对误差、百分比、是否≤50 mm、是否人工、失败原因。缺标志、错误ID、错误布局、极端透视、不完整边界、不合法人工角点都应拒绝或复核。模拟测试通过只证明受控图像链路可行，现场误差仍待验证。
