# 构件分割第一版训练

本轮已完成，实际训练 45 轮。评估结果与失败样例见 [第一版模型训练结果](09_第一版模型训练结果.md)。当前有效评估目录为 `outputs/segmentation-v1/evaluation-mask-v2/`。

## 目标

从照片自动分割带标志的目标构件上表面，替换上一轮试验中的人工构件边界。模型输出像素轮廓；150 mm 标志与几何算法负责毫米尺寸。模型不直接学习文件名中的长宽数值。

本轮采用 YOLO11n-seg 预训练权重微调，在本机 CPU 上建立可复现基线。电脑为 AMD Ryzen 7 8745H，约 20 GB 系统内存，显卡为 AMD Radeon 780M。本轮没有配置 GPU 训练。YOLO11 分割模型提供 n/s 等规格，参考 [官方模型说明](https://docs.ultralytics.com/models/yolo11/)。先选择 n 规格适配本机，后续可用相同标注对比 s 规格。

## 标注与分组

- 39 张原图，每张标注一个带标志的目标上表面。没有把水印副本计入样本。
- 标注来源为助手逐张目视选点，坐标基于 768 × 1024 预览，状态为 `draft_needs_domain_review`。不能称为人工专家审核的精确真值。
- 沿外轮廓标注，保留外缘缺角；排除构件侧面、外露钢筋和旁边的板材。内部标志、细钢筋、小遮挡及内部孔洞暂保留在表面外轮廓包络内，本版不用于净面积/孔洞测量。
- 类别为 `marked_component_top`，背景中没有标志的构件不是本版识别目标。
- 结合视觉与相近卷尺尺寸保守建立 15 个疑似重复分组。相同或相近尺寸不能证明是同一实体，因此分组是临时防泄漏措施，现场构件身份仍待核对。
- 固定训练集 26 张/8 组，验证集 6 张/3 组，留出测试集 7 张/4 组。所有同组照片都在一个集合。
- 测试集不参与优化和最佳权重选择。它们已在本项目中被浏览，部分参与过前期几何开发，故仅称“本轮模型留出测试”，不称现场盲测。

标注源：`samples/real/20260930/segmentation_draft_preview.json`。

分组配置：`config/segmentation-groups.v1.json`。

数据快照：`samples/real/20260930/segmentation-v2/dataset_snapshot.json`，记录原图、导出图及标签的哈希；训练前校验文件未改动。冻结数据禁止覆盖，改标签需生成新版本。首次 v1 导出发现 Windows 换行导致标签哈希记录不一致，已修复导出器并重新生成 v2；v1 未用于训练。

导出图最长边 1280 像素，保持原比例。图像名称只保留照片编号。标签仅包含类别与归一化多边形点，遵循 [Ultralytics 分割数据格式](https://docs.ultralytics.com/datasets/segment/)。卷尺数值不在训练输入中，只有分组和推理后误差评估使用。

## 运行

训练环境为独立 `.venv-train`，与网站的 `.venv` 分开。

```powershell
# 新机器准备环境，版本以 requirements-training.txt 为准
py -3.12 -m venv .venv-train
.\.venv-train\Scripts\python.exe -m pip install -r requirements-training.txt

# 已冻结的数据无需重复生成；新增版本用 --output 指定新目录
.\.venv\Scripts\python.exe scripts/prepare_segmentation_dataset.py

# 训练只用 train / val；保留完整日志与权重
.\.venv-train\Scripts\python.exe scripts/train_component_segmentation.py

# 完成训练后，对 val / test 用固定阈值评估，包含漏检与失败
.\.venv-train\Scripts\python.exe scripts/evaluate_component_segmentation.py

# 对新照片单独输出轮廓；无需输入卷尺尺寸，输出目录须为新目录
.\.venv-train\Scripts\python.exe scripts/predict_component.py "C:\照片\构件.jpg" --output outputs/new-photo-prediction
```

默认参数：预训练 YOLO11n-seg、50 轮上限、512 输入分辨率、batch 4、CPU 4 线程、随机种子 20260930、冻结前 10 层模块、AdamW、初始学习率 0.001、耐心值 15。增强只用于训练集；关闭拼图、混合和复制粘贴，保留小幅旋转、缩放及亮度变化。

`requirements-training.txt` 固定主要依赖，`requirements-training-lock.txt` 保存本次完整环境版本。完全复现时安装完整锁定文件需另加 `--extra-index-url https://download.pytorch.org/whl/cpu` 获取 CPU 构建。

`outputs/segmentation-v1/training_status.json` 记录实际状态、已完成轮数、版本与权重哈希。`outputs/training/component-v1-cpu/` 保存训练结果、配置、曲线及 `weights/best.pt`。实际完成轮数以记录为准，不能以默认轮数代替。

本轮采用本地训练，关闭训练库的数据同步和外部实验记录集成。

## 评估口径

预测阈值固定 0.25，按最高置信度选取目标，禁止根据人工真值挑选预测。报告逐图候选数、置信度、与标注草稿的掩膜 IoU；漏检计为 0。IoU 是轮廓重叠程度，不是测量精度或成功率。

仅当模型轮廓能稳定简化为四边形且找到足够标志时尝试尺寸反算，其他情况保留人工处理/重拍状态。标志定位沿用前期传统图像算法候选，没有将其冒充为已训练的标志模型。

模型测试照片少、标签尚未现场复核、照片来自同一场地，初版结果不能证明对新场地、新手机、遮挡和极端视角可靠。先保留为试验模型，再补标志角点、复核构件身份、扩充照片并测试完整测量链路。
