# 照片模型接入网站（2026-10-01）

本地网站现在可以直接调用已训练的构件分割模型，以及轮廓优化、普通数字卡片补检与平面标定流程。本轮没有重新训练，也没有扩大验证数据集。

## 使用

运行项目根目录的 `start-workbench.ps1`，访问 http://127.0.0.1:8765/ 。

1. 默认选择“真实照片识别（试验）”。
2. 上传原始照片，填写构件编号及标志黑色外框的实测边长。本批标志为 150 mm。
3. 核对标志与被测上表面齐平，点击“识别并计算尺寸”。
4. 查看轮廓图、试验长宽及复核原因。结果自动保存到本机历史，可下载 JSON。

真实照片模式不填写构件设计长宽、卷尺长宽或标志相对布局。至少需要三个可靠且分散的卡片候选；候选不足、边界不稳时不输出尺寸。C1、C2 等是候选编号，不是卡片上的数字识别结果。

原有 ArUco 布局模式和模拟演示保留。该模式要求实测标志布局，且支持人工选四角。照片模型模式暂不支持网页人工四角修正或透视校正图，相应按钮不可用。

## 本地实现

- `POST /api/v1/photo-inspect` 接受 multipart：image 为图片，payload 为 JSON。
- 必要参数：marker_size_mm 正数、conditions_confirmed=true；component_id 最多 100 字。
- 图片上限 20 MB、3200 万像素；统一 EXIF 方向后再推理。
- 网站仍用 `.venv`；模型由 `.venv-train` 内的 Python 子进程运行，默认 CPU，超时 180 秒。
- 同时只处理一张测量照片，忙时返回 429；环境或权重缺失返回 503；无效图片/参数返回 422；超时返回 504。
- 不上传企业照片。服务仍仅绑定本机 127.0.0.1，未发布公网或接入 VPN/元筑。
- 模型必须存在于 `outputs/training/component-v1-cpu/weights/best.pt`。若把网站复制到其他电脑，需另行准备训练环境和权重。

结果的 success 仅表示算出了尺寸。照片流程允许 REVIEW、EXPERIMENTAL_MEASUREMENT、RETAKE、MANUAL_REQUIRED、INVALID_INPUT；拒绝模型返回 PASS。设计偏差表只用于原 ArUco 模式，不把试验照片当验收结论。
