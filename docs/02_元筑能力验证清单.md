## 暂定接入方式

优先：元筑文件输入 → API节点 → 独立测量服务 → 结构化字段及图片存储 → 结果展示。只有 B1—B4 完整通过才考虑代码节点内运行视觉核心；核心模块始终保持独立。

本地已实现 `POST /api/v1/inspect`，旧路径 `/api/inspect` 保留兼容。multipart 包含 `image` 文件及 `payload` JSON 字符串；payload 包含构件编号、设计长宽、`marker_size_mm`、`tolerance_mm`、完整 `layout`、`conditions_confirmed`及可选 `manual_corners`。现阶段接收完整布局，尚未实现服务端布局注册表；不能仅传 `layout_id`。布局配置是测量基准，不可省略或使用设计尺寸替代。URL输入方式需要平台鉴权与下载策略验证后再确定，不默认允许服务任意抓取URL。

返回 `success` 表示有没有有效测量；`result` 包括 `PASS`、`REVIEW`、`MANUAL_REQUIRED`、`RETAKE`、`INVALID_INPUT`。失败尺寸为 `null`，包含机器可读原因。展示用图片 URL 的形成方式待 E1 验证；本地 PoC 的路径不应直接当作平台 URL。
