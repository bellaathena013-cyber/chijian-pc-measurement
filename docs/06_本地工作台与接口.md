# 本地工作台与接口

在项目目录运行 `./start-workbench.ps1`，打开 http://127.0.0.1:8765 。停止时在运行服务的终端按 Ctrl+C。无需 VPN。

## 演示与真实照片

点击“运行模拟演示”会重新执行识别与计算，不是展示缓存数字。演示使用模拟照片、150 mm 标志和示例布局；结果标明模拟来源。

真实照片：选择照片、填写设计长宽与实际标志黑边尺寸，展开“现场标志布局”。四标志按矩形摆放且纸张顶部同向时，可直接填写实测横、纵中心间距；ID 为左上 0、右上 1、右下 2、左下 3。其他布局上传完整 JSON，上传文件优先于间距输入。核对共面条件后开始测量。布局格式见 `config/layout.example.json`，其中位置仅为模拟示例，必须替换为现场实测坐标。

“最近测量”显示本机最近 30 次已完成请求，包括无法获得尺寸的结果。可以重新查看图片和下载 JSON。历史查看不覆盖左侧新测量参数，也不能直接编辑旧照片；重新测量请重新上传照片。

有标定结果时可点击“手动修正四角”，沿构件边界顺序点击四点；已有自动边界时可直接拖动，或点击“重新选四角”。坐标输入框支持键盘调整。提交后重新经过标志和几何质量检查。

每次测量创建独立结果目录。界面展示原图、标注图、透视校正图、尺寸偏差和结果 JSON 下载。尺寸参数变化后清除旧结果。

## HTTP 接口

- `GET /api/health`：健康检查。
- `GET /api/runs`：最近 30 次测量摘要。
- `POST /api/v1/inspect`（旧路径 `/api/inspect` 保留兼容）：multipart/form-data，`image` 为图片文件，`payload` 为 JSON 字符串。
- `GET /api/runs/{run_id}/{filename}`：下载该次测量允许公开的图片或结果 JSON。
- `GET /docs`：自动生成的接口文档。

payload 字段：`component_id`、`design_length_mm`、`design_width_mm`、`marker_size_mm`、`tolerance_mm`、`layout`、`conditions_confirmed`；可选 `manual_corners` 为 EXIF 归一化原图像素坐标的四组数值。`demo: true` 仅用于内置模拟案例。

HTTP 200 不代表尺寸通过。调用方必须查看 `success` 与 `result`，只有 `result=PASS` 表示本轮原型门禁通过。422 为请求参数错误，413 为上传超限，429 表示服务正在处理另一张图片。接口返回图片相对 URL；外部平台接入时需要配置可访问的基址。

## 部署边界

默认只监听本机 127.0.0.1，不含账号鉴权。图片保存在本地 `outputs/web/`；本轮未建立自动清理策略。尚未完成元筑连通、上传格式、鉴权、超时及图片展示实测，不能直接作为企业公网服务部署。

现场精度仍需真实照片与卷尺真值验证；页面操作成功不等于精度已达标。

## 本轮验证

2026-09-19：39 项测试通过（原有测量测试 31 项，新增接口测试 8 项）。覆盖模拟调用、图片上传、人工角点重测、损坏图片、非法参数、结果下载及非允许主机拒绝。测试依赖产生两条弃用提示，不影响本轮通过结果。

浏览器实际操作验证：自动演示测量为 3998 × 997 mm；修改第一个角点 X 坐标后重新测量为 3995.37 × 997.05 mm，界面正确显示“人工四角”。未上传直接运行有明确提示。窄屏表单与结果表可正常浏览。

后续功能更新：增加现场矩形布局输入和最近测量。接口测试现为 10 项，全部通过，新增版本化入口、历史摘要、未完成/损坏记录过滤验证。浏览器验证历史图片恢复、禁止编辑历史结果，以及修改输入后清除旧结果。OpenAPI 定义已导出至 `docs/openapi.json`，在线版本位于 `/openapi.json`。
